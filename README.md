# Cotizador Soccer Factory

Versión lista para GitHub Pages.

## Publicar
1. Sube `index.html` a la raíz del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda.

El PDF usa la plantilla aprobada de Soccer Factory embebida en el propio `index.html`.

> Nota: jsPDF se carga desde cdnjs, por lo que se necesita conexión a internet para generar PDFs.
